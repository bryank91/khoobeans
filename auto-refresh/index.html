What Auto Refresh does

  • Reloads the current Safari tab at an interval you choose.
  • Offers preset intervals and a custom interval from 1 second to 7 days.
  • Keeps the refresh setting active across reloads in that tab, without affecting other tabs.

Frequently asked questions

How do I enable Auto Refresh?

Open the Auto Refresh app and select Open Safari Extension Settings. Enable Auto Refresh in Safari, then use Safari’s View → Customize Toolbar menu to add the Auto Refresh toolbar item if needed. Open a webpage, click the toolbar item, choose an interval, and select Start Auto Refresh.

Which tabs are refreshed?

Only the Safari tab that is active when you start Auto Refresh is refreshed. Your other tabs are not affected.

Why does Safari ask for website access?

Safari requires website access for the extension to run its refresh timer in webpages. This lets the timer continue after the tab reloads. Auto Refresh does not use this access to inspect page content, read forms, or access browsing history.

How do I stop Auto Refresh?

Open the Auto Refresh toolbar item again in the tab and select Stop. The setting also clears when that tab or its browsing session closes.

Privacy policy

Auto Refresh does not collect, transmit, sell, or share personal information, website data, browsing history, form entries, or page content. It has no accounts, analytics, advertising, tracking, or network requests.

To resume the timer after a reload, the extension stores only its enabled state and selected interval in a namespaced sessionStorage entry in the current tab. This local state is not sent to the developer or any third party, and is cleared when the tab or its browsing session closes.
